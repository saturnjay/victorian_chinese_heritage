# Victorian Chinese Heritage — GitHub Pages folder

Upload this complete `docs` folder to a GitHub repository without changing its
internal file names or directory structure.

In the repository, open **Settings → Pages**, choose **Deploy from a branch**,
select the `main` branch and the `/docs` folder, then save.

GitHub will provide the public website address after deployment finishes.
Background map tiles and external research links require an internet connection;
the webpage, interface code, logo and finding photographs are stored locally in
this folder.
